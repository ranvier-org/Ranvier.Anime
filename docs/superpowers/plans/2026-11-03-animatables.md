## Questions the source traces must settle

The source getter reads the tween cache, not the current external target. A numeric getter and retarget start call the modifier on that cache. Component getters expose a live array; partial retargets update only supplied existing components. Determine which of these observations require preservation and document any deliberate safe native adaptation, such as returning snapshots instead of exposing mutable arrays.

Duration/ease omitted on a later retarget retain earlier settings. Source reset(true) refreshes caches without target writes; an ordinary public Reset may introduce an observable extra write. A group's callback animation has its own default duration and can complete before a long property does. Trace actual engine traversal, rather than replacing this with an assumed all-properties-complete rule.

Existing NumericAnimation.Retarget reads the accessor and has fixed duration, so it is not yet an adequate implementation of this family. Reuse its proven timing/guard machinery where appropriate, while allowing a different internal layout for mutable endpoints and timing.

Closing the reference checkpoint does not close the animatable family. Component/CSS slots, callback scheduling, reentry/lifetime and actual native execution remain required.

## Mutable timing checkpoint

Stretch prepares source geometry before interrupting active scheduling, retains raw time, callback flags and clock anchors, and refreshes bounded time/progress getters immediately. It independently normalizes total and iteration duration at eleven decimal places, scales signed delay and loop gaps from the unrounded requested duration, and treats an unchanged normalized total as a true no-op. Numeric and typed declaration renderers use the live iteration/delay and scale their cached tween time. Stretch itself performs no property dispatch or lifecycle callback.

Native input/lifetime adaptations: precise input must be finite and nonnegative; scaled delay overflow rejects before changing geometry or the pending frame. Maximum finite input is supported when its scaled delays stay finite. Cancelled controllers remain terminal. A geometry-changing stretch from a callback or modifier interrupts the stale outer operation; an idempotent stretch preserves it. The four timer lifetime/input regressions and two declaration regressions pin these guarantees.

## Group callback checkpoint

An internal AnimatableGroup now manages initialized property tracks and the separate default 1000 ms callback animation. Property begin resumes it, resetting the same callback object after completion; property pause/completion completes it when every property is paused. Callback reset retains its clock history and identity. Revival is restricted to the internal callback driver; public cancelled controllers remain terminal.

Animatable roots share an ordered queue per supplied Ranvier FrameScheduler instance. The queue uses the source engine's cached-next traversal and 240 FPS admission. A callback root appended while an earlier root already has a next sibling can run in that frame; appending from the last visited root waits until the next frame. Root identities retain position while renewing frame leases. Cancellation versions prevent old leases from cancelling replacement requests. Closing adapters prunes owned roots and leases without disposing the shared host scheduler. Forwarded timeout/microtask registrations expire on completion or disposal.
